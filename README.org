#+TITLE: MerrinxUI

A modular UI suite for World of Warcraft: Forever (interface 16001). Each module can be
enabled on its own, and they all share one look and one options window.

* Modules
| Module         | What it does                                                         |
|----------------+----------------------------------------------------------------------|
| ActionBars     | Action bars with opacity, mouseover, combat hiding and a key toggle  |
| Auctioneer     | Gold-based buy plan, sell prices, profit ledger and price trends     |
| BuffReminders  | Shows your class buffs when they are missing or running low          |
| CastBars       | Player, target and focus cast bars, plus a swing timer               |
| Chat           | Chat window skin, fading, clickable URLs and a copy-chat window      |
| CooldownVoice  | Announces tracked spells coming off cooldown by voice or sound       |
| DamageMeter    | Multi-window damage, healing, interrupt, dispel and death meter      |
| EnemyCooldowns | Tracks enemy players' cooldowns on their nameplates                  |
| EnemySpotter   | Lists nearby enemy players and alerts on a kill-on-sight list        |
| HideBlizzard   | Hides the Blizzard frames that MerrinxUI replaces                    |
| Nameplates     | Styled nameplates with cast bars, debuffs, crowd control and markers |
| Professions    | Profession levelling guides                                          |
| QoL            | Tabs: Performance (FPS, latency, memory, CPU) and Layer Hop          |
| RangeText      | Range to your target, coloured by spell range                        |
| SpellHistory   | Recently cast spells as icons or bars                                |
| UnitFrames     | Player, target, focus, pet and target-of-target frames               |
| XPBar          | Experience bar with rested and completed-quest XP                    |

Shared parts: global font and bar texture (via LibSharedMedia-3.0), frame mover
with grid snapping, per-character or shared profiles, and built-in diagnostics.

* Usage
| Command                    | Effect                                     |
|----------------------------+--------------------------------------------|
| =/mui=                     | Open the options window                    |
| =/mui unlock=, =/mui lock= | Unlock or lock frames for moving           |
| =/mui debug on=            | Turn on debug mode                         |
| =/mui test=                | Run the self-checks and show the log       |
| =/mui log=                 | Show the debug log                         |
| =/mui copy=                | Copy chat                                  |
| =/mui hop=                 | Hop to another layer                       |
| =/mui ah=                  | Show or hide the Auctioneer window         |
| =/mui kos [name]=          | Add your target or a name to the kill list |

* Installation
Download =MerrinxUI-<version>.zip= from the GitHub releases and extract it into
the client's =Interface/AddOns/= folder. Restart the client fully after an
update so new media files are picked up.

* Development
The project is built with Nix; the dev shell provides Lua 5.1, busted, luacheck,
stylua and lua-language-server.

#+begin_src sh
nix develop            # dev shell (or direnv)
nix flake check        # specs, lint, format, syntax and package checks
nix build .#release    # result/MerrinxUI.zip
#+end_src

Libraries (Ace3, LibRangeCheck-3.0, LibSharedMedia-3.0) and the bundled textures
and sounds are fetched or generated by the flake, so they are not in the
repository. Pure logic lives in =*Logic.lua= files with specs under =spec/=.

Releases are published by CI when a tag =v<version>= matching =## Version= in
=MerrinxUI/MerrinxUI.toc= is pushed; tags with a suffix (=v1.0.0-rc.1=) become
prereleases.
