* Goal
Add a debug mode to MerrinxUI so the user can test every feature from inside the game without pasting =/run= probe scripts:
- A "Debug mode" toggle (options UI and =/mui debug=).
- With debug mode on, a "Run tests" button (and =/mui test=) runs a self-test of *every* feature and writes PASS / FAIL / SKIP / INFO lines to a log.
- A log window shows the whole log preselected; the user presses Ctrl+C and pastes it back to the agent, which fixes whatever failed.
- While debug mode is on, features also write short trace lines at their state changes (SD5), so behaviour that can't be checked from state (an enemy cast, a combat relock) shows up in the same log.
- Extensible by contract: every feature added later appends its own checks, and a busted guard fails =nix flake check= when a runtime file in the TOC has none, so new features are automatically part of the test button.

* Scope
In scope:
- New =MerrinxUI/Debug/DebugLogic.lua= (pure) and =MerrinxUI/Debug/Debug.lua= (the "Debug" Ace module, =ns.Debug=).
- A check contract: =Module:GetDebugChecks()= for Ace modules, =ns.Debug:RegisterChecks(source, provider)= for non-module runtime files (Util now, Options later).
- Checks for every current feature: Core, Mover, Combat, Hider, RangeText, HideBlizzard, EnemyCooldowns, Nameplates (including the 0.8.0 health text / power / debuff work).
- =EnemyCooldownLogic.Audit= (the S11 P3 probe as a pure, tested function).
- busted specs: =spec/debug_logic_spec.lua=, =spec/debug_coverage_spec.lua=, Audit cases in =spec/enemy_cooldown_logic_spec.lua=.
- =/mui debug [on|off]=, =/mui test=, =/mui log= routed from =Core.lua=.
- Trace log calls at state-change points in the existing features (SD5).
- Lead-owned update of =merrinxui-plan.org= so later sections (S7-S9, S14-S17) add checks and use =/mui test= at their game gates.

** =ns.DebugLogic= (=MerrinxUI/Debug/DebugLogic.lua=, pure, busted)
#+begin_src lua
DebugLogic.CAP = 500          -- log lines
DebugLogic.MAX_LINE = 400     -- chars per log line
DebugLogic.MAX_PART = 200     -- chars per described value
DebugLogic.STATUSES = { PASS = true, FAIL = true, SKIP = true, INFO = true }

DebugLogic.Describe(v, isSecret) -> string
-- isSecret(v) first, before type(). secret -> "<secret>"; nil -> "nil"; boolean -> "true"/"false";
-- number -> tostring; string -> "\n"/"\r" become " ", "|" becomes "||", cut to MAX_PART then "...";
-- anything else -> type(v). Never indexes tables, never errors.
DebugLogic.Join(parts, n, isSecret) -> string        -- Describe(parts[1..n]) joined by " "; n keeps nil gaps
DebugLogic.FormatLine(stamp, source, text) -> string -- "[" .. stamp .. "] " .. source .. ": " .. text, cut to MAX_LINE
DebugLogic.Push(log, line, cap) -> removed           -- append, then drop oldest until #log <= cap (cap >= 1)
DebugLogic.Flatten(tbl, isSecret) -> string          -- "k=v" sorted by key; nested tables one level as "k.sub=v"; deeper -> "k.sub=table"
DebugLogic.RunCheck(check, ctx, isSecret) -> { name, status, detail }
DebugLogic.RunChecks(source, checks, ctx, isSecret) -> results   -- order kept; each result gets .source; nil checks -> {}
DebugLogic.RunSource(source, provider, ctx, isSecret) -> results
-- pcall(provider); throw -> { {source=, name="checks", status="FAIL", detail="error: " .. Describe(err)} };
-- non-table, non-nil return -> { {source=, name="checks", status="FAIL", detail="not a table"} }; else RunChecks
DebugLogic.FormatResult(r) -> string                 -- "FAIL EnemyCooldowns/spell table: mismatched 6346 180000 30000"
DebugLogic.Summary(results) -> text, counts          -- "12 checks: 9 PASS, 1 FAIL, 1 SKIP, 1 INFO", {PASS=9,FAIL=1,SKIP=1,INFO=1,total=12}
DebugLogic.SortSources(names) -> array               -- "Debug" first, rest alphabetical
#+end_src
=RunCheck= error semantics:
- non-table check, or =run= not a function → =FAIL "malformed check"=;
- =run= throws → =FAIL "error: " .. Describe(err)= (a secret error reads =error: <secret>=);
- status nil, secret or not in =STATUSES= → =FAIL "invalid status: " .. Describe(status)=;
- a non-string name goes through =Describe=;
- otherwise =detail = Join(values after status)=.

=RunTests= order:
1. =Log("Debug", "test run", version, interface, classFile, locale, "combat", InCombatLockdown())=.
