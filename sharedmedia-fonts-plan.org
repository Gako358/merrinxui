* Goal
The user has the *SharedMedia* font pack (Elkano) installed, together with the standalone *LibSharedMedia-3.0* addon. None of the pack's fonts show up in MerrinxUI's font lists (Media "Global font" and the per-module Font selects).

Goal: every font and bar texture the pack ships that actually loads on the Forever client can be selected and applied in MerrinxUI.

The root cause is not visible in the code, and the candidate causes need different fixes (see "Decision table"). So the plan has two parts:
1. A diagnostic release (SM1), checked with =/mui test= at a game gate.
2. The fix for the branch that the evidence selects (SM2).

The user pre-approved the MerrinxUI-side workaround (W1) for *fonts and bar textures* (D-SM-05).
